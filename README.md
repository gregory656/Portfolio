🧊 Overview

> A high-impact, production-grade portfolio built with React and Firebase, crafted to showcase real-world engineering skills through performance, clarity, and modern UI design.


---

⚙️ Tech Stack

⚛️ Frontend

React — scalable component architecture

JavaScript (ES6+) — clean & modern syntax

Tailwind / CSS — glassmorphism & responsive design

Framer Motion — fluid micro-interactions


 Backend & Services

Firebase Authentication — secure access

Firestore — real-time database

Firebase Hosting — fast global delivery

Firebase Storage — media handling



---

 Features

🚀 Lightning-fast performance
🧊 Glassy modern UI
📱 Fully responsive (mobile → desktop)
🔐 Secure authentication
⚡ Real-time data sync
🌍 Live production deployment


---

🧩 Architecture

src/
├── components/     # Reusable UI components
├── pages/          # App routes
├── firebase/       # Firebase configuration
├── assets/         # Images & icons
├── styles/         # Global styling
└── utils/          # Helper functions

Clean, modular, and scalable.
